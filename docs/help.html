PageGloss 使用说明

划词标记 + 自配置 LLM 解释。全部数据只保存在本机浏览器里。

三步上手

  1. 打开扩展设置页，填写接口地址（如 https://api.deepseek.com）、API Key 与模型名，点「测试连接」。
  2. 在网页上选中一个词或一句话，点右键，选「PageGloss：标记并解释」。
  3. 页面中所有相同文本会被同色标记，鼠标悬停在标记上即可看到解释卡片，可在卡片里继续追问。

取消标记

  • 在某个标记上点右键，选「取消此处标记」：只去掉这一处。
  • 在标记上点右键，选「取消该词的全部标记」：去掉该文本的所有位置。
  • 点扩展图标，在「本页标注」里逐条删除，或点「清空本页全部标记」。

三种上下文方式

在扩展图标的弹窗里切换，切换后会自动刷新当前标签页以套用新策略。

方式发送给模型的内容
整页正文（默认） 页面全部正文 + 该段文本所在的完整句子。理解最充分，token 消耗最高；页面超长会自动截断。
所在章节 + 关键片段 该文本所在段落/章节 + 完整句子 + 全页去重后的关键片段。成本明显更低。
仅所在句子 该段文本所在的完整句子与相邻各一段。最省 token。

快捷键

Alt + Shift + G：开启 / 暂停 PageGloss 的划词标记。

Esc：关闭当前注释卡片。

数据与隐私

  • 标注位置、颜色与聊天记录按网址保存在 chrome.storage.local。
  • 系统提示词只在你每次提问时临时使用，不会写入页面的标注缓存。
  • API Key 仅保存在本机，只会发送给你填写的接口地址。
  • 在设置页可导出全部数据为 JSON，或一键清空。
